# Навыки мобильного UX и оформления MAUI

В проект скопированы три полных каталога из [davidortinau/maui-skills](https://github.com/davidortinau/maui-skills).

- Исходный каталог: `plugins/maui-skills/skills/`.
- Зафиксированная версия: [`79bb4bfd8f671ed0dd97bdf92a36430928e8d984`](https://github.com/davidortinau/maui-skills/tree/79bb4bfd8f671ed0dd97bdf92a36430928e8d984/plugins/maui-skills/skills).
- Дата копирования: 10 октября 2026 года.
- Лицензия: MIT, полный текст сохранён в [MAUI_SKILLS_LICENSE.txt](MAUI_SKILLS_LICENSE.txt).

| Навык | Назначение | Файлы из источника |
|---|---|---:|
| [ux-first-principles](ux-first-principles/SKILL.md) | Принятие UX-решений: иерархия, понятность, нагрузка на внимание, доступность | 5 |
| [ux-mobile](ux-mobile/SKILL.md) | Мобильные сценарии: касания, управление одной рукой, навигация и небольшой экран | 1 |
| [maui-theming](maui-theming/SKILL.md) | Темы .NET MAUI: светлый / тёмный режим, ресурсы и переключение оформления | 2 |

Все восемь файлов сохранены без изменения содержимого, включая пять справочных файлов в `references/`. У `ux-mobile` в этой версии источника нет вспомогательного каталога. Размеры и Git blob-хэши каждого файла сверены с исходным коммитом GitHub.

Для работы над мобильным UX сначала читаются `ux-first-principles` и `ux-mobile`; для реализации тем — `maui-theming`. Дополнительные ссылки на другие навыки в их текстах не означают, что эти другие навыки установлены: подключены только три перечисленных каталога.

Это инструкции для агента внутри данного репозитория, не зависимости приложения. Они не добавляют NuGet-пакетов, не меняют интерфейс и не устанавливают Android / Apple SDK. Обновление копий выполняется отдельно с повторной проверкой источника и сохранением лицензии.
