# Установка NutriFlow на свой iPhone

Проверено по официальным источникам 8 октября 2026 года. Способ установки пока не выбран пользователем; ниже — рекомендация и подготовка, не выполненная установка.

## Что уже готово

[Run 37773708893](https://github.com/Vvvv4a40/NutriFlow/actions/runs/37773708893) подтвердил Release / `ios-arm64` / Mono AOT на облачном Mac. Артефакт сборки содержит `.app` внутри `NutriFlow-ios-arm64-without-apple-signing.tar.gz` и отдельный device lock; отчёт и журналы опубликованы другим, диагностическим артефактом. Самой IPA, Apple-подписи, provisioning profile и установки на телефон нет. Техническая ad-hoc подпись симулятора не заменяет подпись для телефона.

Сборка на Windows по-прежнему требует доступа к Apple build tools на Mac; свой Mac покупать не нужно для уже настроенной облачной проверки. GitHub runner компилирует, но не подключает физический iPhone. [Публикация MAUI iOS](https://learn.microsoft.com/en-us/dotnet/maui/ios/deployment/publish-cli?view=net-maui-10.0).

Клиент пока показывает один статичный экран. Установка этого клиента не добавит дневник, серверное подключение, камеру или голос: это следующие отдельные изменения.

## Рекомендация и компромиссы

Для личной проверки с Windows и без платной подписки рекомендуется **AltStore Classic с AltServer**, не AltStore PAL. У проекта есть [официальная Windows-инструкция](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows). Это сторонний инструмент, не продукт Apple; пользователь самостоятельно решает, доверять ли ему свой аккаунт.

У бесплатного варианта приложения перестают открываться по истечении семи дней, если подпись не обновлена. AltStore пытается обновлять её в фоне, но это не гарантия: нужны доступный AltServer и соединение с ним; можно использовать ручной Refresh All. Не рассчитывайте на постоянную работу без периодического доступа к компьютеру. Бесплатный лимит — три sideloaded-приложения одновременно; AltStore тоже занимает место. [Обновление приложений](https://faq.altstore.io/altstore-classic/your-altstore).

Apple отдельно подтверждает семидневный срок профиля Personal Team. Платный Apple Developer Program указан по цене 99 USD в год или доступному местному тарифу; он открывает другие способы распространения, но тоже требует настройки сертификатов / профилей, а не делает нынешний tar установочным. Ничего покупать или регистрировать автоматически не нужно. [Сравнение программ Apple](https://developer.apple.com/support/compare-memberships/).

Первый бесплатный Windows-маршрут NutriFlow ещё не проверен. По результатам источников это рекомендуемый план, не обещание совместимости нашей конкретной IPA со всеми версиями AltServer / iOS. Успех означает только будущую фактическую установку и запуск на телефоне.

## Три понятия без лишних деталей

- **IPA** — пакет приложения iOS для передачи инструменту установки. Формат упаковки сам по себе не даёт разрешения на запуск: отдельно нужны подходящая подпись и профиль. Текущий tar нельзя просто переименовать в `.ipa`. [Публикация и подпись MAUI](https://learn.microsoft.com/en-us/dotnet/maui/ios/deployment/publish-cli?view=net-maui-10.0).
- **Сертификат и закрытый ключ** — часть механизма подписи. Подпись позволяет проверять подписавшего и целостность кода; имя сертификата без ключа недостаточно для подписания.
- **Provisioning profile** — профиль разрешённых условий запуска. Для development он связывает App ID, сертификаты и зарегистрированные устройства. В бесплатном Windows-маршруте эту настройку выполняет локальный инструмент с аккаунтом пользователя, не NutriFlow и не текущий GitHub workflow. [Состав development profile](https://developer.apple.com/help/account/provisioning-profiles/create-a-development-provisioning-profile/).

## Что понадобится лично пользователю, если выбран AltStore

Не устанавливайте всё сразу: сначала подтвердите маршрут. Пароль, код подтверждения, ключи и профиль в чат не отправляются.

1. Скачайте AltServer для Windows с [официального сайта](https://altstore.io/). iTunes / iCloud и поддерживаемый способ установки берите из [инструкции AltStore для Windows](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows), не со случайных зеркал. Она рекомендует версии Apple вне Microsoft Store; для Store iCloud есть отдельная [инструкция совместимости](https://faq.altstore.io/altstore-classic/troubleshooting-guide). Не удаляйте существующие Apple-программы или данные вслепую.
2. Подключите разблокированный iPhone кабелем, подтвердите доверие компьютеру и настройте Wi-Fi sync по руководству. Apple Account и пароль вводите самостоятельно только в выбранном инструменте. AltStore заявляет, что данные направляются Apple; это заявление проекта, не результат аудита его сетевого трафика в NutriFlow.
3. Установите AltStore на телефон через AltServer, подтвердите доверие своему профилю. На iOS 16+ руководство требует Developer Mode; изменение этой настройки и подтверждение на телефоне выполняются лично пользователем. Названия пунктов настроек могут отличаться между версиями iOS.
4. После подготовки отдельной NutriFlow IPA проверим подпись / установку и первый экран на телефоне. Затем отдельно проверим обновление подписи до истечения срока. Нынешний tar симулятора или устройства для этого шага не выдаётся за готовую IPA.

Нам достаточно сообщения «AltStore готов» и модели iPhone / версии iOS, без email, паролей, серийного номера или UDID в публичном репозитории. Для первичной проверки AltServer не нужны Android SDK / JDK, OpenAI / Groq ключи или регистрация NutriFlow в App Store.

## Что будет следующим техническим изменением

После выбора бесплатного пути — отдельная упаковка проверенного device bundle в IPA для последующей локальной подписи, с проверкой структуры и без Apple-учётных данных в CI. Текущий unsigned verifier останется отдельной проверкой исходного пакета: он намеренно отклоняет provisioning profile и не должен ослабляться ради подписанного результата. Конкретный упаковщик и native-проверка относятся к следующему шагу.

После выбора платного пути — отдельная подготовка безопасной подписи с сертификатом / профилем. Приватный ключ, `.p12`, пароль и подписанный профиль нельзя коммитить, печатать в логах или публиковать общим артефактом. Текущий workflow с `contents: read` не требует этих данных; добавление secret-based signing не выполняется заранее.

Подпись / установка / запуск остаются непроверенными до настоящего результата на устройстве. Ручная приёмка должна подтвердить открытие NutriFlow, а не только появление иконки. Переподпись инструментом может изменить bundle ID; итоговый идентификатор и совместимость нужно проверить отдельно. Подписанный пакет нельзя проверять unsigned-скриптом как исходную неподписанную сборку.
