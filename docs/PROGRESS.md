## Среда и репозиторий

- Git-репозиторий инициализирован; ветка `main` отслеживает `origin/main`.
- Установлен .NET SDK 10.0.302; консольный проект нацелен на .NET 10.

## Этап 3

- расчётные классы вынесены из консоли в библиотеку `NutriFlow.Domain`;
- консольный проект ссылается на доменную библиотеку и отвечает только за демонстрационный сценарий и вывод;
- создан отдельный проект `NutriFlow.Domain.Tests` с xUnit-тестами;
- направление зависимостей остаётся односторонним: Console → Domain и Tests → Domain;
- добавлены проверки неотрицательных КБЖУ, обязательных имён и объектов, положительных масс, непустого блюда и допустимой порции;
- тестами покрыты сложение и масштабирование КБЖУ, расчёт ингредиента, всего блюда, значений на 100 г, порции и основные ошибочные входные данные;
- промежуточные значения по-прежнему не округляются.

## Этап 4

- добавлена дневная цель `DailyGoal`;
- `MealEntry` хранит название, массу и зафиксированные КБЖУ съеденной порции;
- `DailyProgress` принимает цель и несколько записей приёма пищи;
- дневной прогресс детерминированно рассчитывает съеденные, оставшиеся и превышенные значения по каждому показателю;
- остаток и превышение представлены отдельно, поэтому физические значения КБЖУ остаются неотрицательными;
- пустой день считается допустимым, а переданный список записей защищён от последующих внешних изменений;
- консольный сценарий показывает съеденные порции, дневную цель, сумму и остаток;
- дата, хранение, пользователи, API и сессии ввода в этот этап не добавлялись.

## Этап 5

- добавлен неизменяемый `InputEvent` для хранения одного исходного текстового сообщения;
- `CaptureSession` хранит события только добавлением и сохраняет порядок их поступления;
- жизненный цикл сессии представлен состояниями `Collecting`, `ReadyForReview` и `Confirmed`;
- завершить пустую сессию, подтвердить её слишком рано или изменить после подтверждения нельзя;
- сессию в состоянии просмотра можно снова открыть, не удаляя прежние сообщения, и добавить исправление новым событием;
- наружу передаётся коллекция только для чтения, а изменяемый список остаётся внутри сессии;
- консольный сценарий явно показывает, что исходные сообщения пока хранятся без автоматического разбора;
- парсер, структурированный черновик, вопросы, фотографии, AI, API и хранение не добавлялись.
