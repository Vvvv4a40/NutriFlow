## Сейчас

Этап 1 — завершён.

## Среда и репозиторий

- Git-репозиторий инициализирован; ветка `main` отслеживает `origin/main`.
- Установлен .NET SDK 10.0.302; консольный проект нацелен на .NET 10.

## Этап 1

- ранний черновик преобразован в законченный расчёт КБЖУ одного продукта;
- добавлены конструкторы и свойства только для чтения;
- единицы измерения отражены в именах свойств;
- промежуточные значения рассчитываются с типом `decimal` без округления;
- результат выводится в консоль вместе с исходными значениями на 100 г;
- демонстрационный сценарий явно отделён от справочных пищевых данных;
- устранены два предупреждения nullable-анализа из этапа 0.

## Проверка

- `dotnet build .\NutriFlow.sln --no-restore` — успешно, 0 ошибок и 0 предупреждений.
- `dotnet run --project .\NutriFlow.Console\NutriFlow.Console.csproj --no-build` — успешно.
- Контрольный пример для 250 г сверен одноразовой smoke-проверкой консольного вывода: 500 ккал, 25 г белков, 20 г жиров и 60 г углеводов.
